📱 Guide PWA

Installer KCalTrack
sur Android

Transformez l'application web en vraie app Android en quelques minutes — sans Play Store, sans code complexe.

🌐
Méthode 1 — GitHub Pages (gratuit, recommandée)
Héberger l'app en ligne gratuitement et l'installer sur Android
1
Créer un compte GitHub

Allez sur github.com et créez un compte gratuit si vous n'en avez pas.

2
Créer un nouveau dépôt public

Cliquez sur New repository, nommez-le kcaltrack, cochez "Public" puis Create repository.

3
Uploader les fichiers

Cliquez sur Upload files et glissez TOUS les fichiers du dossier kcaltrack-pwa/ (en respectant la structure avec le dossier icons/).

4
Activer GitHub Pages

Allez dans Settings → Pages, choisissez la branche main, racine /, puis Save. Attendez 2 minutes.

5
Votre URL sera :

https://VOTRE-PSEUDO.github.io/kcaltrack/

6
Installer sur Android

Ouvrez l'URL sur Chrome Android → menu ⋮ → "Ajouter à l'écran d'accueil". L'app apparaît comme une vraie application !

💡 Une bannière d'installation apparaîtra automatiquement dans l'app après quelques secondes.
💻
Méthode 2 — Serveur local (pour tester chez soi)
Tester l'app sur votre réseau WiFi local
1
Installer Node.js

Téléchargez Node.js sur nodejs.org (version LTS).

2
Lancer un serveur local

Dans un terminal, naviguez dans le dossier kcaltrack-pwa/ et tapez :

npx serve . -l 3000

3
Accéder depuis votre téléphone

Trouvez l'IP de votre PC (ex: 192.168.1.10) et ouvrez http://192.168.1.10:3000 sur Chrome Android.

⚠️ Le Service Worker (mode hors-ligne) ne fonctionne qu'en HTTPS ou localhost. Pour une vraie installation, utilisez GitHub Pages.
